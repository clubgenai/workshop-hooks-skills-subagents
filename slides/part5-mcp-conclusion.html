MCP — Rappel

Model Context Protocol

Standard ouvert qui permet à Claude Code de se connecter à des outils et sources de données externes via un protocole unifié.
2 modes de transport
ModeLatenceUsage
stdio~5msServeurs locaux (90%)
HTTP streamable—Nouveau standard
Commandes essentielles
# Ajouter GitHub MCP
claude mcp add github -- \
  npx -y @modelcontextprotocol/server-github

# Lister les serveurs
claude mcp list

# Inspecter dans Claude Code
/mcp

💡 MCP est le "USB-C" de l'IA — un seul standard pour brancher n'importe quel outil.

La combinaison gagnante

1

🧩 Skill "code-review" — Charge les instructions et standards d'équipe

2

🤖 → Subagent "security-reviewer" — Analyse isolée dans son propre contexte

3

🪝 → Hook PostToolUse — Formate automatiquement, sans que Claude ne décide

4

🔌 → Serveur MCP GitHub — Crée la PR directement dans votre écosystème

Ces 4 mécanismes se complètent naturellement dans un workflow réel.
