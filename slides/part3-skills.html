🧩 Skills

Skills — Fondamentaux

Qu'est-ce qu'une Skill ?

Un dossier d'instructions, de scripts et de ressources que Claude charge dynamiquement pour améliorer ses performances sur des tâches spécifiques.
Structure
ma-skill/
├── SKILL.md        ← Requis
├── references/     ← Docs détaillées
│   └── api.md
├── scripts/        ← Scripts exécutables
│   └── validate.sh
├── assets/         ← Ressources
└── evals/          ← Tests
    └── evals.json

Où les placer ?

PROJET .claude/skills/
USER ~/.claude/skills/

💡 Analogie : guide d'onboarding pour un nouvel employé. Pas besoin de réexpliquer le contexte à chaque session.

Skills — Progressive Disclosure

Claude ne charge que ce dont il a besoin

La quantité de contexte est effectivement illimitée.

1

name + description

Claude décide si la skill est pertinente pour la tâche.

Toujours en mémoire
2

Contenu du SKILL.md

Instructions détaillées, processus, contraintes.

Si pertinente
3

Fichiers de référence, scripts, assets

Chargés uniquement si la tâche les requiert.

Si nécessaires
Skills — Format

Le fichier SKILL.md

---
name: nom-de-la-skill
description: |
  Ce que fait la skill
  et QUAND l'utiliser  ← crucial !
model: haiku
allowed-tools: [Bash, Read]
---
# Nom de la Skill        ← obligatoire
## Ce que tu dois faire  ← obligatoire
Instructions détaillées...
## Gotchas               ← optionnel
- Ne jamais faire X car...
- Toujours vérifier Y avant...

⚠️ Le champ description est crucial

C'est ce que Claude lit pour décider d'utiliser la skill. Soyez précis sur les déclencheurs.

Options du frontmatter

model haiku · sonnet · opus
allowed-tools liste blanche d'outils
