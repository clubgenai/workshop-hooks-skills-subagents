🪝 Hooks

Hooks — Fondamentaux

Qu'est-ce qu'un hook ?

Commandes shell qui s'exécutent à des points précis du cycle de vie — toujours, quoi que décide le modèle.
Prompt / Instructions

Claude PEUT décider de le faire… ou non.

Hook

Claude VA le faire, systématiquement.

💡

Analogie : hooks Git pre-commit, post-push — sauf que c'est pour votre agent IA

Hooks — Cycle de vie

Les événements

Début de session
SessionStart Démarrage / reprise de session
UserPromptSubmit Avant que le prompt atteigne Claude
Exécution d'outils
PreToolUse Avant l'exécution — peut bloquer
PostToolUse Après — feedback possible
Fin de session
Stop Claude a fini — peut forcer continuer
SubagentStop Fin d'un subagent
PreCompact Avant compaction du contexte

Les hooks PreToolUse et UserPromptSubmit peuvent bloquer l'action via exit code.

Hooks — Mécanismes

Handlers & exit codes

4 types de handlers
command
Script shell ~90% des cas · <5ms
http
Requête HTTP POST Vers un endpoint externe
prompt
Évaluation LLM Via Claude Haiku
agent
Spawn d'un subagent 30–60s · cas complexes
Exit codes
0

Succès

L'action est autorisée, l'agent poursuit.

1

Feedback

Stderr transmis à Claude comme contexte.

2

Blocage

L'opération est annulée immédiatement.

Tout ce que vous écrivez sur stderr est transmis à Claude comme feedback.

Hooks — Configuration

Structure de configuration

{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          {
            "type": "command",
            "command": "..."
          }
        ]
      }
    ]
  }
}

matcher = expression régulière sur le nom de l'outil

Niveaux de portée
NiveauFichier
USER~/.claude/settings.json
PROJET.claude/settings.json
LOCAL.claude/settings.local.json
📌

PROJET → versionnable en git

🔒

LOCAL → non commité, secrets

Hooks — Atelier pratique

Formatage automatique

TP 1

PostToolUse → Prettier sur chaque fichier JS/TS édité

📁

Chemin dans le repo

hooks/tp1/post-tool-use

📂

À placer dans votre projet

.claude/hooks/

Objectif

Tout fichier JS/TS modifié est automatiquement formaté. Claude ne décide pas.

Test

Demandez à Claude de créer un test-hook-formatage.js mal formaté → il doit être nettoyé automatiquement.

Hooks — Atelier pratique

Hook de sécurité

TP 2

PreToolUse → bloquer les commandes dangereuses avant exécution

📁

Chemin dans le repo

hooks/tp2/pre-tool-use

📂

À placer dans votre projet

.claude/hooks/

Hooks — Atelier pratique

Contexte au démarrage

TP 4

Trigger : SessionStart — injecter le contexte à chaque ouverture

#!/bin/bash
echo "Dossier : $(pwd)"
echo "Date : $(date '+%Y-%m-%d %H:%M')"
ls
Write-Output "Dossier : $(Get-Location)"
Write-Output "Date : $(Get-Date -Format 'yyyy-MM-dd HH:mm')"
Get-ChildItem

Objectif

Claude reçoit automatiquement le contexte de votre environnement à chaque session.

Test

Démarrez une nouvelle session → Claude doit mentionner votre dossier actuel spontanément.
